# Скоуп MVP: максимально узко, чтобы быстро получить играбельную версию

> Обновление: после первого рабочего MVP продукт осознанно расширен —
> добавлены уровни ставок, докупка фишек и турнирный Sit & Go формат
> (см. `docs/03-implementation-notes.md`). Ниже — исходный план для
> истории; он остаётся ориентиром по духу (один чёткий формат за раз,
> не усложнять раньше времени), просто фактический скоуп чуть шире.

Принцип Lichess на старте — не пытаться закрыть всё сразу. У Lichess на старте
были просто шахматы и возможность играть с другом/случайным соперником.
Для покера аналог:

## Входит в MVP

- Один вариант игры: **No-Limit Texas Hold'em**
- Один формат стола: 6-max (6 игроков за столом) либо heads-up (1 на 1) —
  выбрать один для старта, не оба
- Вход без регистрации: заходишь, получаешь временный ник/аватар (как гостевой
  режим в PokerTH), садишься за стол
- Два способа начать игру:
  1. "Быстрая игра" — одна кнопка, матчит со случайными игроками/ботами
  2. "Стол по ссылке" — создал стол, скинул ссылку друзьям, сели и играете
     (это самый низкий порог входа и самый вирусный механизм на старте)
- Виртуальные фишки без денежной стоимости, без доната за фишки, без вывода
- Базовый UI стола: карты, банк, стек каждого игрока, таймер на ход,
  кнопки действий (фолд/колл/рейз/чек) с понятными подсказками для новичков
- Честная раздача (минимум — крипто-ГПСЧ, см. `research/03-fairness.md`)

## Осознанно не входит в MVP (откладываем)

- Турниры и мультистоловые форматы
- Рейтинговая система (ELO-подобная для покера считается сложнее, чем в
  шахматах из-за высокой дисперсии — не блокер для MVP, но требует отдельного
  продуманного решения позже)
- Другие варианты покера (Omaha, Short Deck и т.п.)
- Аккаунты с полноценным профилем/статистикой/историей — на старте достаточно
  гостевого режима + опциональной привязки (e-mail или OAuth) для сохранения
  прогресса между визитами
- Мобильное приложение — веб, адаптивный под мобильный браузер, достаточно
- Чат/соцфункции — можно добавить позже, не критично для первой игры

## Критерий готовности MVP

Друг может открыть ссылку в браузере, за 10 секунд (без установки и регистрации)
сесть за стол с другим человеком и сыграть полноценную раздачу NLHE без багов
и без необходимости объяснять интерфейс.
