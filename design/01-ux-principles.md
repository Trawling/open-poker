# Принципы UX/UI: минимализм и "без гемора"

Ориентир — lichess.org: заходишь на главную, видишь одну явную кнопку "Играть",
без модалок, без обязательной регистрации, без рекламы, без заманух.

## Принципы

1. **Один главный экран, одно главное действие.** На главной — не более
   одной-двух кнопок ("Быстрая игра", "Создать стол для друзей"). Всё
   остальное (правила, о проекте, код на GitHub) — второстепенно, в футере/меню.
2. **Ноль обязательных шагов перед игрой.** Без регистрации, без e-mail,
   без подтверждения возраста модалкой на весь экран (достаточно строки в футере).
3. **Понятность для новичка прямо за столом.** Если человек не знает, что такое
   "рейз" или "позиция дилера" — у кнопок и зон стола должны быть ненавязчивые
   подсказки/тултипы, а не отдельный учебник, который надо читать до игры.
4. **Нейтральная, спокойная палитра.** Тёмный фон по умолчанию, зелёное сукно —
   по желанию (можно и без него — чистый нейтральный фон тоже ок), без мигающих
   анимаций выигрыша в стиле казино-автоматов.
5. **Честная статистика без давления.** Никаких "залогинься, чтобы не потерять
   прогресс!" всплывающих окон каждые 2 минуты.
6. **Скорость.** Стол должен открываться мгновенно, ходы применяться без
   видимой задержки — ощущение "живого" стола критично для доверия и
   удовольствия от игры.
7. **Доступность.** Достаточный контраст текста/карт, поддержка клавиатурных
   действий (пробел = чек/колл и т.п., как горячие клавиши в Lichess для ходов).

## Референсы для изучения (помимо Lichess)

- PokerTH web client — посмотреть, что НЕ делать (устаревшая эстетика,
  перегруженный интерфейс)
- Любой минималистичный карточный веб-сервис (например интерфейсы современных
  light-weight карточных игр на Phoenix LiveView, упомянутые в research) —
  хороший пример "стол без лишнего"

## Визуальный язык (принято по референсам пользователя)

Текущая реализация (`frontend/src/styles.css`) следует конкретному визуальному
стилю вместо абстрактного "просто тёмная тема":

- **Матовое стекло (glassmorphism), а не сплошные тёмные панели.** Почти все
  плашки интерфейса (места игроков, банк, бейджи, панель действий, история
  раздач) — полупрозрачные с `backdrop-filter: blur()`, видно, что происходит
  "сквозь" них. Общий `.glass` utility-класс в `styles.css`. Это сознательный
  выбор в духе современного "эппловского" дизайна (Control Center/macOS), а не
  казино-эстетика сплошных чёрных панелей.
- **Стол — мягкое зелёное свечение по центру, без деревянного борта.**
  Никакого реалистичного сукна с рамкой — `radial-gradient` прямо на тёмном
  фоне страницы, дальше от центра просто растворяется в черноте.
- **Карты игроков "тянутся" к центру стола** — рубашки карт каждого игрока
  рисуются ближе к центру, чем его аватар/ник, как на реальном столе
  (а не прямо под аватаром с краю).
- **Рубашки карт — полупрозрачное стекло**, не сплошная заливка: сквозь них
  должно быть видно зелёное свечение стола. Открытые карты (общие на столе и
  свои собственные) — наоборот, полностью непрозрачные, читаемость важнее.
- **Зелёный — единственный яркий акцент** (кнопка колла, активный ход, рамка
  своего места), везде остальное — приглушённые оттенки серого на чёрном.
- Референсные картинки (`image.jpg`, `test2.jpg` в корне репозитория у
  разработчика) в сам репозиторий не коммитятся (см. `.gitignore`) — это
  просто мудборд для сверки, не актив проекта.

## Статус вайрфреймов

Сделано напрямую в виде рабочего UI (не отдельных макетов) — см.
`frontend/src/pages/Home.tsx` и `frontend/src/pages/Table.tsx`. Проверено
скриншотами через headless Chromium на десктопной и мобильной ширине.
