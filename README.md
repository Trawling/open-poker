# Open Poker — открытый покер-сервис в духе Lichess

[![CI](https://github.com/Trawling/open-poker/actions/workflows/ci.yml/badge.svg)](https://github.com/Trawling/open-poker/actions/workflows/ci.yml)
[![License: AGPL v3](https://img.shields.io/badge/License-AGPL%20v3-blue.svg)](LICENSE)

Идея: бесплатный, без рекламы, open-source сервис для игры в покер (Texas Hold'em в первую очередь),
максимально минималистичный и понятный — зашёл и сразу играешь, без регистрации, доната и шума.

Это рабочий каталог проекта. Все материалы — исследования, решения по архитектуре, макеты — складываем сюда.

## Структура папки

- `research/` — изученные аналоги, юридические нюансы, выводы по рынку
- `docs/` — архитектурные и продуктовые решения (ADR, roadmap, спецификации игры)
- `design/` — UX/UI референсы, вайрфреймы, принципы минимализма
- `backend/` — будущий код сервера (игровой движок, матчмейкинг, API)
- `frontend/` — будущий код клиента (веб-интерфейс стола)
- `assets/` — графика, иконки карт/фишек, шрифты

## Быстрый старт (локально)

```bash
npm install
npm run dev
```

Откройте http://localhost:5173 — бэкенд поднимется на http://localhost:4000.
Нажмите «Быстрая игра» в двух вкладках браузера (или дождитесь бота —
он подключится автоматически через несколько секунд, если партнёра нет).

Прогнать тесты движка: `npm run test`
Прогнать сквозной smoke-тест (нужен запущенный backend): `node scripts/smoke-test.mjs`
Проверить, что стеки переживают перезапуск сервера: `node scripts/persistence-test.mjs`

## Деплой на сервер

```bash
cp .env.example .env
docker compose up --build
```

Подробности, переменные окружения и настройка домена с HTTPS — `docs/04-deploy.md`.
